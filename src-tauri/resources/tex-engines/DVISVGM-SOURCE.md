# dvisvgm source availability

The complete TeXKey distribution contains an unmodified Apple Silicon slice
of the dvisvgm executable distributed with MacTeX 2025:

- dvisvgm version: 3.4.3
- TeX Live binary package revision: 73806
- original signing team: Richard Koch / MacTeX (`RBGCY5RJWM`)
- bundled SHA-256:
  `22d4e7fdcccea79d11dad95e59c500f4884ab94e2d419862a2908c96f2b91e80`

dvisvgm is licensed under GNU GPL version 3 or, at the recipient's option,
any later version. The complete corresponding TeX Live 2025 program sources,
including the build system and the library sources used by the TeX Live
binary build, are available from:

- https://ftp.tug.org/historic/systems/texlive/2025/texlive-20250308-source.tar.xz
- https://github.com/TeX-Live/texlive-source/tree/branch2025

The upstream dvisvgm 3.4.3 source is also available from:

- https://github.com/mgieseki/dvisvgm/tree/3.4.3

These source locations must remain available alongside any public download of
the TeXKey distribution that contains dvisvgm. A redistributor is responsible
for satisfying the source-conveyance requirements of GPLv3 section 6.
